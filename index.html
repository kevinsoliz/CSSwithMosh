SE Principle: Separation of concerns

HTML y CSS son dos diferentes concerns. Tenemos que separar nuestro código de manera organizada. Por eso es preferible usar CSS externo o embebido en lugar de inline. El CSS inline es más difícil de mantener y no se puede reutilizar fácilmente. Además, el CSS inline puede causar problemas de rendimiento y accesibilidad.

Normalize CSS

No todos los browsers muestran los estilos tal como los codificamos, por eso hay que usar esta plantilla de estilos para que todos los browsers muestren los estilos de manera consistente. Vas a tener que incluirlo en todos tus proyectos.
