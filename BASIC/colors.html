Gradients

Aquí tienes un gradient generator:

Pincha aquí.

Hay navegadores que no soportan gradientes asi que tendras que poner un color plano de fondo como fallback.

Por ejemplo:

.box2 {
  background: linear-gradient(to right, #ff7e5f, #feb47b);
  background-color: #ff7e5f; /* Fallback color */
}

En este caso, si el navegador no soporta gradientes, se mostrará el color #ff7e5f como fondo.

Los gradientes lineales se crean con la función linear-gradient(), mientras que los radiales se crean con la función radial-gradient().
